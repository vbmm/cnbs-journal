# CNBS Journal

Local, fully-offline voice trade journal (macOS, arm64).

- Speak or type a trade note → local STT (Parakeet) + local LLM (Qwen3.5) structure it
- Day logs (pre/post session), leak tags, 2-loss rule, guided weekly review
- Prop-firm style accounts with $/R + rule gauges
- Auto-updates via GitHub Releases on launch

Releases: see the Releases tab (the .app bundle + update packages live there).
